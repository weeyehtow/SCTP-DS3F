## Introduction to NumPy

How do you create a Numpy array with the shape (3,6) filled with zeros?
Response given: np.array((3,6)
Correct Response: np.zeros((3,6))

What is the result of the following code
	arr2d[1, 2]?
Response given: The third element of the second column of arr2d.
Correct Response: The third element of the second row of arr2d.

What is the result of the following code
	arr2d[1][2] = 12
Response given: It changes the third element of the second column of arr2d to 12.
Correct Response: It changes the third element of the second row of arr2d to 12.

How do you compute the union of two arrays arr1 and arr2?
Response given: np.union(arr1, arr2)
Correct Response: np.union1d(arr1, arr2)

How do you compute the dot product of two arrays arr1 and arr2?
Response given:np.cross(arr1, arr2)
Correct Response: np.dot(arr1, arr2)

## Introduction to Pandas

How do you create a new Series with the default index and the data [2.5, 4.0, 5.5, 6.75]?
Response given: pd.Series(values=[2.5, 4.0, 5.5, 6.75])
Correct Response: pd.Series([2.5, 4.0, 5.5, 6.75])

How do you drop the columns 'two' and 'four' from a DataFrame named 'data'?
Response given: data.drop('two', 'four', axis=1)
Correct Response: data.drop(['two', 'four'], axis=1)

What is the difference between loc and iloc indexing in Pandas?
Response given: loc indexing refers to the position, while iloc refers to the index label
Correct Response: loc indexing refers to the index label, while iloc refers to the position

How do you apply a function to each column of a DataFrame named 'frame'?
Response given: frame.apply(func, axis='columns')
Correct Response: frame.apply(func)

How do you return unique values of the index pd.Index(['a', 'b', 'c', 'a'])?
Response given: pd.Index(['a', 'b', 'c', 'a']).distinct()
Correct Response: pd.Index(['a', 'b', 'c', 'a']).unique()

How do you create a new column 'age' in a DataFrame named 'df' with a scalar value of 25?
Response given: df.insert('age', 25)
Correct Response: df['age'] = 25
